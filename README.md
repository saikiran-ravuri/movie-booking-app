
# 🎬 Movie Booking Application

A full-stack, responsive MERN (MongoDB, Express, React, Node.js) movie ticket booking platform with real-time seat selection, authentication, and payment integration.

🚀 **Live Frontend App:** https://movie-booking-application-sai.netlify.app  
⚙️ **Live Backend API:** https://movie-booking-app-backend-awzt.onrender.com

---

## ✨ Features

- 🔐 **User Authentication:** Registration, Login, JWT-based security, Forgot/Reset password via OTP email.
- 🍿 **Movie & Theatre Browsing:** Browse movies by genre, language, and explore showtimes across theatres.
- 🎟️ **Real-Time Seat Booking:** Interactive seat grid with dynamic pricing and seat selection.
- 💳 **Payment Gateway Integration:** Stripe checkout integration for online ticket purchasing.
- 📱 **Fully Responsive:** Sleek, modern design optimized for desktop, tablet, and mobile browsers.

---

## 🛠️ Tech Stack

- **Frontend:** React, Vite, TailwindCSS, Axios, React Router DOM
- **Backend:** Node.js, Express.js, Mongoose, JWT, Nodemailer, Stripe SDK
- **Database:** MongoDB Atlas (Cloud Database)
- **Deployment:** Netlify (Frontend), Render (Backend)

---

## 🚀 Local Setup & Installation

### 1. Clone the repository
git clone https://github.com/saikiran-ravuri/movie-booking-app.git
cd movie-booking-app

### 2. Configure & Run Backend Server
cd server
npm install
npm run dev

### 3. Configure & Run Frontend Client
cd ../client
npm install
npm run dev
